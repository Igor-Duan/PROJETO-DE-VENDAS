
# Projeto de BI - Análise de Vendas

Projeto de análise de vendas desenvolvido para praticar Business Intelligence,
tratamento de dados e criação de dashboards.

## Ferramentas
- Excel
- SQL
- Python/Pandas

## Conteúdo
- Tratamento e análise dos dados
- Indicadores de vendas e lucro
- Dashboard interativo
